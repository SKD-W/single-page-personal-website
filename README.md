# single-page-personal-website

A single-page personal website I built from scratch using **HTML, CSS and JavaScript**. No templates or frameworks were used.

## About

This website introduces me, Ojiezele Collins Osas, a Frontend Developer based in Nigeria. It shows my background, work experience, education, projects, skills and some pictures of me and my friends.

## Sections

- **Home** – my picture, name, role and a greeting
- **About** – a short bio about me
- **Experience** – my work experience, education and certification
- **Projects** – projects I have built, like Empowered2Play
- **Skills** – the tools and technologies I use
- **Gallery** – pictures of me and my friends
- **Contact** – my contact details and a contact form

## Features

- Responsive design that works on mobile and desktop
- Mobile menu that opens and closes with a button
- Greeting that changes based on the time of day
- Gallery pictures open bigger when clicked
- Contact form that checks all fields are filled before sending
- Footer year updates automatically
